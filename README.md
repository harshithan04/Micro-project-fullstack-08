# 🎓 Student Quiz Application 

A Django-based **Student Quiz Application** developed as a project for Full Stack Development.

This application allows teachers (admins) to create subjects and quizzes, and students to take quizzes and view their scores.

---

## 🧠 Project Description

The **Student Quiz Application** is designed to help teachers manage quizzes and monitor student performance.  

### **Features**
- 👩‍🏫 **Admin (Teacher)** can:
  - Add subjects and questions  
  - Manage student profiles  
  - View and evaluate scores  

- 🧑‍🎓 **Student** can:
  - Register and log in  
  - Attempt quizzes created by the teacher  
  - View quiz scores after submission  

---

## ⚙️ Technologies Used
- **Backend:** Django (Python)
- **Frontend:** HTML, CSS, Bootstrap
- **Database:** SQLite3
- **Version Control:** Git & GitHub
